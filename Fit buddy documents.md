- FitBuddy is a web-based application that uses AI to generate personalized workout plans and nutrition tips based on a user’s fitness goals, such as weight loss, muscle gain, or general wellness. Built with FastAPI and integrated with Google’s Gemini AI model, FitBuddy simplifies the process of creating structured and effective fitness routines.
- The application takes in user information—like age, weight, goal, and preferred workout intensity—and generates a customized 7-day fitness plan. Users can also submit feedback to update and refine their plan using AI. A complementary nutrition or recovery tip is also provided based on their selected goal.
- With a clean user interface and database support via SQLite, FitBuddy ensures each user’s data and generated plans are stored and accessible. It offers both API endpoints and an interactive HTML interface for ease of use.

## Scenarios

### Scenario 1: Personalized Workout Plan

A user inputs their personal details including name, age, weight, fitness goal (e.g., “weight loss” or “muscle gain”), and preferred workout intensity (“high”, “medium” or “low”) to receive a personalized 7-day workout plan. The system generates a day-by-day schedule tailored to the user’s fitness objective and experience level. This AI-driven customization enhances user motivation and adherence by providing structured and goal-specific routines.

### Scenario 2: Feedback-Based Plan Update

A user submits feedback on their existing workout plan, such as suggesting changes like “more focus on cardio” or “include more rest days.” The system uses this input to regenerate an updated workout plan, making it more suitable for the user’s evolving needs. This feedback loop ensures that users stay engaged and receive dynamic fitness support as their preferences or progress change.

### Scenario 3: Nutrition or Recovery Tips

A user requests a nutrition or recovery tip based on their selected fitness goal. The platform delivers a concise and relevant suggestion (e.g., “Include protein in your post-workout meal” for a muscle-gain goal), which complements the workout plan. These targeted tips help users improve results by aligning their diet and recovery practices with their physical training regimen.

### Scenario 4: Admin Dashboard

An admin or coach accesses the platform to view all registered users and their workout plans through a dedicated dashboard. This view allows them to track individual progress, compare original and updated plans, and monitor user activity. It provides oversight for trainers managing multiple clients or students.
